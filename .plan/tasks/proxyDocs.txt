proxyDocs — README: dummy key, injector, egress

Why:
People who want a nested ssa (or any script) to call the model
without putting sk-… in the sandbox can point OPENAI_URL at a
local reverse proxy and set OPENAI_API_KEY to a dummy value. The
proxy holds the real Bearer token. The harness never puts the
master key in messages.json. A one-upstream injector is not an
open forward proxy and is not an egress firewall: scripts can
still curl the world unless the sandbox has no other path.
Competent network admins already know how to force that. ssa
should not grow a proxy or new flags. README Safety today covers
ask-user and --sandbox-command only. securityModel.txt is the
README Safety frame (trust, layers, leftovers); this task is
only the injector recipe under that.
