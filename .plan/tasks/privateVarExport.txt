privateVarExport — inherited export on internal names

Why:
AGENTS.md says PID, PROMPT_COUNTER, TEMP_FOLDER are not exported.
Assigning an inherited exported variable does not necessarily drop
the export attribute. If a caller exported PID, model scripts may
still see it.

Do:
Unset private names before defining them, or narrow the guarantee in
AGENTS.md. Unset+set is the robust fix.

Tests:
Hard in the fake-curl stories. A small check that the sandbox script
does not see PID is possible if you export PID in the test env before
run_ssa_task.
