completeSentinel — # complete instead of # task complete

Why:
The done marker is two words. A one-word sentinel matches
# write file: / # edit file: as a short first action line.
Decided: switch to exact # complete. Do not wait for
requireReplySentinels.

Do:
Replace # task complete with # complete everywhere it is a
done marker (exact match, leading notes skipped, trailing
newlines ignored). System prompt, FORMAT_ERROR_* text, -h
loop sentence, AGENTS.md stop rule, first_action_line,
agent_is_done, and the status line. Prefer one short status
phrase (do not keep "task complete" in the UI). Do not accept
both markers.

A script note that says # complete as the first action line
becomes done. Same class of collision as today's sentinels.
Do not add a format-error retry for that here.

Size:
About 2 net new (0–5), about 8–15 lines touched. Substitutions,
not new control flow. Tests and AGENTS.md are extra, not in
that count.
