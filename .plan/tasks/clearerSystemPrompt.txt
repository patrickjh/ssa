clearerSystemPrompt — rewrite SYSTEM_PROMPT so the four shapes
are harder to mix

Why:
The system prompt is the model's protocol. Today it is easy to
misread. A labeled "# comment:" next to "# write file:" looks like
another sentinel (Gemma 4 31B concatenates those examples; see
mixedReplyKinds.txt). Write is "preferred" then a script may also
heredoc. Harness talk ("first action line", leading notes skipped)
is repeated under write and done. The one-shape rule sits above
four long examples, so it is easy to miss.

This task is copy only. It does not change dispatch, ask, or
format-error recovery.

Do:
Rewrite SYSTEM_PROMPT. Keep the four shapes (bare script, write,
edit, done). Make the copy harder to mix:

- Drop or rename the labeled "# comment:" example. Keep
  "Put reasoning in # comments".
- One short rule at the top: exactly one shape per reply, no
  markdown fences, no thinking tags.
- Do not explain first_action_line. If notes-before-sentinel
  stay, one short sentence, not repeated under write and done.
- One story for file bytes: write/edit preferred. Do not also
  advertise heredoc/printf as a second path (or one clause, not
  a second recipe).
- Keep the write/edit/done examples short. Do not grow the
  prompt into an essay.

Do not add # script (requireReplySentinels.txt). The done line is
# complete. Do not change FORMAT_ERROR_* unless a sentence
now contradicts the prompt. Do not change first_action_line,
reply_is_*, or handle_model_response. Keep -h short; this is not
help text. Do not copy the new prompt into -h or README.

mixedReplyKinds.txt keeps the harness fallback if models still
concatenate after this lands. Do not add that detection here.

Size:
A rewrite of SYSTEM_PROMPT (~0–10 net). 0 harness. AGENTS.md only
if Design quotes the old example (it does not today). Tests extra,
not in that count.

Tests:
None unless a canned reply copied "# comment:" and that example
goes away (today none do). showHelp does not print SYSTEM_PROMPT.
Fake curl stories still pass. A live Gemma smoke is optional, not
a tests/ story.
