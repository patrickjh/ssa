the system prompt and can see its own last turn. Distinct
strings diagnose harness predicates; they do not teach a shape

already collapsed to one FORMAT_ERROR.

static FORMAT_ERROR. Keep the checks (blank, fence, think tags,
sh -n). Every format-error path records the same text. Drop the
argument to record_format_error if only one string remains.

of the right one. Today's shapes: a POSIX sh script, # write

fired (empty vs fence vs invalid sh). Do not name env vars.

the spec with the prompt is formatErrorInPrompt.txt.

it. Those are results, not format.
