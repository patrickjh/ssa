envOnlySettings — maybe drop CLI flags, settings from env only

Why:
Every user-facing setting has both a flag and an env var. The flag
parser, six set_* helpers, the Options block in -h, and die hints
that say "use --flag or ENV" are a large slice of ssa (~70–80
lines). New settings (--context, --review-work) each add another
flag, setter, and help paragraph. Env prefixes already work
(SSA_NO_ASK=1 ssa task). Undecided. Do not treat this as required
work.

This is a maybe. It trades Unix long-options for a smaller file and
cheaper new knobs. It is one way to land contextFile and reviewWork
under a ~1000-line ssa without cutting ask/write/edit. It is not
enough for a # subagent shape too (see subAgents.txt).

Do:
Decide first. If no: keep flag+env as AGENTS.md Settings and CLI
says today. If yes: one breaking change, not a mix. Do not keep -m
as the last value flag unless you explicitly want that exception.

If you drop flags: settings are env only (OPENAI_*, SSA_*). Keep
-h / --help and collecting the task from argv (and stdin). Keep
rejecting unknown -* so a mistyped flag is not a task word. Drop
parse_arguments flag arms, all set_* functions, and the Options
section; put the meaning in Environment (not "See --foo"). Die
hints name the env var only. CLI no longer overrides env.

Keep -h on stdout, exit 0. Booleans stay 0|1 (SSA_NO_ASK=1, not
--no-ask). OPENAI_API_KEY in the environment is the better secret
path; --openai-api-key can show in ps.

Update AGENTS.md Settings and CLI (every setting is env only; no
"flag overrides env"). Keep -h short. Caller's shell already does
per-run overrides (VAR=value ssa …).

Size:
If no: 0. If yes: about 70–80 lines removed from ssa, not added.
set_* ~35, parse_arguments ~8–12, -h Options folded into
Environment ~20–25, shorter die strings ~6–8. ssa is 949 today;
after this ~870. Review + context then fit under 1000; # subagent
still does not. Later settings skip a flag/setter/help arm
(contextFile closer to 40–50 than 50–70). Tests, README, and
AGENTS.md are extra, not in that count.

Tests:
If no: none. If yes: every run_ssa / CLI flag in tests/*/*.test.sh
moves to env (especially --no-ask, --keep-temp, -m, --openai-url,
--sandbox-command). showHelp still covers -h. A mistyped flag
still dies. Flag-overrides-env stories go away. Fake curl,
--no-ask stories become SSA_NO_ASK=1.
