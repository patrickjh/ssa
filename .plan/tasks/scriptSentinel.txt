scriptSentinel — required # script, payload on a pipe

Why:
Leftover-as-script is the odd kind: write, edit, and complete start
with #, and the prompt says to put reasoning in # comments. Gemma 4
31B then comments out the program (`# ls -la`). sh -n accepts that,
ssa runs it, nothing happens. A required first action line # script
(exact, no runner) matches the other kinds. Payload is everything
after that line. Do not also accept a bare script.

experiments/formatError/ssa already does this. Do not copy # run /
SSA_RUNNER from runSentinel. maybeNot/requireReplySentinels.txt
wanted a payload temp file; do not add one. sed the tail off
latestModelResponse.txt, same idea as write -c.

Do:
Copy the formatError fork's dispatch, not the whole file.

- first_action_line keeps # complete, # write file:, # edit file:,
  and # script. Drop ^[^#]. # script is exact like # complete.
- Unknown first action line is a format error (comments-only and
  leftover-as-script included). Empty payload after # script is a
  format error (empty | sh -n succeeds).
- script_payload: sed -n '/^# script$/,$p' | sed 1d from
  MODEL_RESPONSE_FILE. No SCRIPT_PAYLOAD_FILE. sh -n and sandbox
  stdin are that pipe. Ask lists the full latestModelResponse.txt
  (leading notes, # script, then the program), same as write/edit.
  Leading notes are not fed to sh.
- Do not pipe into run_in_configured_sandboxes (pipeline subshell).
  Keep the extract | COMMAND inside the helper's existing ( ) so
  EXIT_CODE_FILE and append_script_result still run in the harness.
- Prompt: one # script plus ls -la in the spec. Do not add # run.
  Do not add ask kind labels unless a later job asks.
- Fake first turn is # script then echo starting the agent.
- Every canned tests/ script reply gets # script. Write and edit
  unchanged.

Size:
About 15 lines in ssa (12–20). Prompt is a few edited lines in the
spec, not a second SYSTEM_PROMPT. Tests and AGENTS.md extra.

Tests:

ls runs; notes before # script are not on sh stdin. Empty # script
is a format error. emptyWritePathRunsAsScript becomes a format
error. trailingDoneCommentIsNotDone still runs (# complete is in
the payload). Fence and think tags still retry. Write/edit still
lack Format error.
