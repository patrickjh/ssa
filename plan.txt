1) Review AGENTS.md

Read AGENTS.md. It should say how to edit this repo, the
style rules, and what stays out. It should point at ssa
for behavior.

Cut any sentence that restates what ssa or README.md already
shows. Keep a rule the code does not show. Fix wording that
the later tasks made stale.

2) Ask several models for changes

Do this after the AGENTS.md review. Have more than one
model read ssa and AGENTS.md. Each model suggests
changes that would improve the project.

Add those suggestions as tasks in plan.txt. Leave ssa
and AGENTS.md as they are.

3) Double check POSIX compliance

ssa is POSIX sh. Read the script for features that are
bash, ksh, or another shell: arrays, [[ ]], process
substitution, local outside a function, and similar.

Check external utility options too. The log uses sed
line ranges. head -c is not POSIX. Replace any other
non-POSIX use, or document the required GNU or BSD
utility behavior.

Fix what is not portable under the stated requirements.
Leave a construct that is already portable and clear.

4) Review the system prompt

Read the system prompt text in ssa. Cut sentences,
examples, and repeated rules that the model can do
without. Keep a rule the harness still needs it to
follow.

Leave the task line and any SSA_EXTRA_SYSTEM_TEXT
in place. Update README.md only if a setting's
meaning would otherwise be unclear.

5) Figure out how to turn reasoning on

Reasoning is off. ssa passes --reasoning off and
--reasoning-budget 0. AGENTS.md says not to add a
thinking trace the device must generate, and it
lists thinking left on, with the trace stripped
from history, as kept out.

Work out a later change that turns reasoning on
and still reads one action per reply. Do not
change ssa, README.md, or AGENTS.md for this task.
When the approach is clear, add it here as the
next task.

The reply and the trace share one stdout. On
current llama-cli the trace is a prefix, marked
by the lines [Start thinking] and [End thinking].
The reader stops at the first line that is exactly
# end. The first action line in that text is the
action. A trace that contains an action line or
# end is taken as the reply.

ssa does not send the model reply back. llama-cli
keeps the chat, so a trace stays in later turns
unless a llama-cli flag drops it. Context shift
drops old turns and keeps the system prompt.

The system prompt tells the model to put reasoning
in # comments and to use no thinking tags. Any
approach has to say what that text becomes.

Say what happens to the low-token goal and the
kept-out line. Leave both as they are until that
decision is written down.
