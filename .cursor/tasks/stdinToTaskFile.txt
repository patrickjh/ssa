stdinToTaskFile — cat stdin into task.txt, not TASK

Why:
task.txt is already what jq uses (--rawfile task). Stdin still goes
TASK=$(cat), then log_task copies the string into the file. That hop
is leftover from before the file existed. $(cat) also strips every
trailing newline and loads the whole task into a shell variable.

Do:
Write stdin straight to $TEMP_FOLDER/task.txt. Keep TASK for argv
(TASK=$* in parse_arguments) until the file is written; drop the
stdin-to-variable path.

Sketch:

- argv set: printf '%s\n' "$TASK" > task.txt (same as today)
- argv empty and stdin not a tty: cat > task.txt
- argv empty and stdin is a tty: do not read; die "no task"
- then check the file is a real task (non-empty after the same
  newline rules as today)

read_task_from_stdin_if_needed currently runs before
setup_temp_folder, so there is no task.txt yet. Create the temp
folder (or at least the task file path) before the stdin write.
check_task_is_set must move to after that write, or split: tty + no
argv can still fail before mkdir; emptiness of a pipe is only known
after cat.

Optional: consume stdin after the other check_can_run checks so a
missing model/url does not drain the pipe. Not required for the hop
removal.

AGENTS.md still says task.txt is "log only". It is the user-message
source. Fix that while here.

Keep:
- [ -t 0 ] so interactive ssa with no argv does not block
- existing die text for no task (CLI words or pipe stdin)
- argv always getting a trailing newline from printf '%s\n'

Match today for empty / newline-only stdin: TASK=$(cat) of only
newlines becomes "" and fails check_task_is_set. Direct cat plus
[ -s file ] would accept that. Do not change that unless you add a
test that says otherwise.

Tests:
tests/completeSimpleTask/taskFromStdin.test.sh must stay green.
No new story folder unless you add a no-task usage case (empty
argv, empty pipe or tty). Do not add tests under oldTests/.

Pitfalls:
- Do not cat stdin into TASK and then copy; the file is the sink.
- Do not drop TASK until argv is on disk; parse_arguments runs
  before the temp folder exists.
- Do not read stdin when [ -t 0 ].
- jq --rawfile includes the file bytes as written; a raw cat with
  no extra newline is a behavior change vs printf '%s\n' after
  $(cat). Decide per source: argv keeps printf; stdin can be cat
  if the empty-task check still treats newline-only as missing.
