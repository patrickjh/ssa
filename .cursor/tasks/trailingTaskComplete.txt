trailingTaskComplete — stop after a script that ends with the done line

Why:
Models often emit a valid script and then # task complete in the same
reply. Today only a first-action-line of # task complete stops the
loop; a trailing done line is ignored (see trailingDoneCommentIsNotDone).

Do:
Optional. If the reply is valid POSIX sh and the last non-empty line
is # task complete, run the script (without that line, or with it as
a comment), then stop on success. Do not treat a done line in the
middle as complete.

Tests:
Story next to completeSimpleTask: echo hello then # task complete,
expect the echo on stdout and done after one model prompt.

Do this after a real run shows wasted extra done-turns.
