rejectGemmaThoughtChannel — treat native thought wrappers as format errors

Why:
Gemma 4 can emit <|channel>thought (and similar) even when think is
off. Those bytes must not be fed to sh. <think> is already grepped.

Do:
In reply_has_thinking_tags (or a sibling), reject <|channel>thought
the same way as <think>. Format error, do not run. Keep writes/edits
skipping this check so file payloads may contain the text.
