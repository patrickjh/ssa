writeFileRequest — model write requests

The model creates or overwrites a file with no heredoc and no shell in
the reply: first action line is "# write file: PATH" (leading blank
lines and # notes skipped) and every line after that sentinel is the
raw file. ssa writes that payload to PATH with sed through the same
ask and sandbox layers as a script. No quoting or escaping applies
to the payload.

Acceptance:
- File lands byte-for-byte (quotes, dollars, backticks, backslashes,
  trailing blank lines)
- Create new file and overwrite existing file
- Success prints "wrote file: PATH" on stdout (and into the transcript)
- Write to a missing parent folder fails; a later mkdir script plus
  retried write recovers
- First line "# write file:" with no path is not a write request; it
  runs as a script
- Path with spaces ("# write file: my file.txt") writes that file
- Leading # notes and blank lines before the write sentinel are not
  part of the file
- Exit 0 after "# task complete"
- Fake curl on PATH; no real network
