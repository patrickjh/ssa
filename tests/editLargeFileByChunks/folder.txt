editLargeFileByChunks — large-file edits via chunk files

The model can still change part of a large file with ordinary scripts
and write requests: split into chunk files, prove the split is
lossless, overwrite one chunk, then join. The prompt does not teach
this; the awk splitter in the test is one way a model might do it.

Acceptance:
- cat chunks/* reproduces the original file before any edit (cmp)
- Overwrite one chunk and join yields the expected full file,
  including blank-line separators
- Chunk folder removed after join
- Exit 0 after "# task complete"
- Fake curl on PATH; no real network
